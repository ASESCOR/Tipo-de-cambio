Preguntas frecuentes

¿Qué representa la cotización P2P?

Es una referencia de compra y venta de USDT frente al boliviano en Binance P2P. Puede variar según monto, medio de pago y contraparte.

¿Qué diferencia hay con el tipo de cambio oficial?

La referencia oficial proviene del Banco Central de Bolivia, mientras que la P2P refleja operaciones entre participantes de un mercado digital.

¿Cada cuánto se actualiza esta página?

Mientras la página está abierta, consulta las cotizaciones actuales cada cinco minutos. Además, GitHub Actions registra una lectura diaria para el histórico.
